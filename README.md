# TRIO – Logic and Mathematical Board Game App

TRIO is a logic-based mathematical game project designed to combine strategic thinking, number reasoning, and interactive gameplay.

The project started as a physical board game and later evolved into a digital mobile application. The main goal of TRIO is to make mathematical thinking more engaging by turning logical operations into a competitive and enjoyable game experience.

## Project Vision

TRIO is built around the idea that games can improve cognitive skills while remaining fun and accessible. The game encourages players to think quickly, recognise numerical patterns, and use mathematical operations strategically.

## Key Features

- Multiple game modes
- Mathematical challenge mechanics
- Logic-based number selection
- Mobile-friendly gameplay
- Clean and modern user interface
- Interactive game screens
- Expandable structure for future versions

## Product Journey

TRIO began as a physical board game concept. After developing the first basic version, I continued improving the product by designing more advanced gameplay versions, testing different rules, and expanding the concept into a mobile application.

The game has gone through several design iterations, including visual improvements, gameplay testing, and digital adaptation. The mobile version represents the next stage of TRIO’s development as a scalable educational and entertainment product.

## Innovation

Unlike traditional number games, TRIO focuses on combining:

- Mathematical reasoning
- Pattern recognition
- Strategic decision-making
- Fast problem solving
- Game-based learning

This makes TRIO suitable not only as entertainment but also as a tool for cognitive engagement.
