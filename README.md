# TRIO

TRIO is a mathematics-based strategy game designed to combine logical thinking, calculation and competitive gameplay.

The project began in 2022 as a physical board game. In 2023, I started developing TRIO as a mobile application, expanding the original concept into a digital product with multiple game modes, user accounts, multiplayer features and social functionality.

The first recorded TRIO software repository and GitHub development activity dates from 23 October 2023.

## About the Project

TRIO was created to make mathematical thinking more interactive and enjoyable.

Many educational games focus mainly on learning, while many entertainment games offer limited cognitive challenge. TRIO was designed to bring these two areas together by using numbers, mathematical operations and strategic decision-making as active parts of the gameplay.

The project currently consists of:

- A commercially distributed physical board game
- A React Native mobile application under active development
- An official website at [trio-game.com](https://trio-game.com)
- Ongoing iOS and Android testing

## Project Timeline

### 2022 — Physical Board Game

TRIO began as a physical mathematics-based strategy game.

During this stage, the core gameplay was developed, tested and improved through live player feedback. The physical product was later prepared for commercial sale, including its board, cards, packaging and visual identity.

### 2023 — Mobile Application Development

The software development phase began in 2023.

The first recorded TRIO GitHub activity dates from 23 October 2023. Since then, the mobile application has continued to grow through new game modes, authentication, user profiles, multiplayer systems and social features.

### 2026 — Official Website

The official TRIO website was launched through the `trio-game.com` domain, giving the project a public digital presence for its physical and mobile products.

## Installation

Clone the repository:

```bash
git clone git@github.com:hasan-aydinoglu/Trio-Ultimate.git
```

Enter the project directory:

```bash
cd Trio-Ultimate
```

Install the dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

The application can then be tested using an emulator, simulator or compatible mobile device.

## Firebase Configuration

TRIO uses Firebase services for authentication, user information, multiplayer data and messaging.

A valid Firebase project configuration is required to run the complete application.

The project uses Firebase for:

- Account registration and login
- User profile storage
- Friend relationships
- Friend requests
- Private messages
- Multiplayer rooms
- Game invitations
- Real-time application data

Sensitive Firebase credentials and private configuration values should not be committed publicly.
